# Tangent

A little topic generator for when you want to think about something other than your to-do list.

Hit draw, get a random, genuinely interesting topic — pulled from a curated library spanning science, history, psychology, space, mythology, and more. Each one comes with a spark question to get your brain moving.

## Why

Sometimes you just want something worth looking into. Not "what's the capital of France," but "why do we cry at movies" or "what would change if we found a habitable exoplanet."

## Features

- 🎲 One-click random topic draw with a fun flip animation
- 🗂️ Filter by category (Science, History, Philosophy, Mythology & Folklore, and more)
- 🌗 Light and dark mode
- 📌 Save topics to a shortlist
- 📋 Copy a topic + question to your clipboard in one click

## Running it locally

```bash
git clone https://github.com/CyrilMyril/tangent.git
cd tangent
npm install
npm run dev
```

## Built with

React + Vite. No backend, no accounts, no tracking — just open it and draw.
